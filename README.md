## Easy Updates via Git (Push & Pull)

This repository is set up with standard Git tracking so you can push and pull changes anytime from your computer:

```bash
# 1. Make your changes to index.html or replace Chirantha_Akarsha_CV.pdf
# 2. Stage changes
git add .

# 3. Commit changes
git commit -m "Update projects and experience"

# 4. Push live to GitHub Pages
git push origin main
```

Within ~30–60 seconds, your website at `https://akarshasac.github.io` will automatically update!
The URL will remain constant forever, so the link on your CV will always lead to your latest work.
